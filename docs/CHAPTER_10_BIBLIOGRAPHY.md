# Chapter 10: Bibliography

## 10.1 Technical Documentation and Frameworks
The development of **ElevateHire** relied on several industry-standard technical resources and official documentation libraries.

- **Flutter Documentation**: Official guide for building cross-platform applications using the Flutter framework.
  - URL: [https://docs.flutter.dev/](https://docs.flutter.dev/)
- **Dart Language Reference**: The core programming language documentation for Dart.
  - URL: [https://dart.dev/guides](https://dart.dev/guides)
- **Supabase Documentation**: Reference for Backend-as-a-Service (BaaS) features including Authentication, PostgreSQL Database, and Storage.
  - URL: [https://supabase.com/docs](https://supabase.com/docs)
- **Riverpod State Management**: Official documentation for the reactive caching and state management library used in the project.
  - URL: [https://riverpod.dev/](https://riverpod.dev/)
- **Material Design 3 (Material You)**: Guidelines for modern UI/UX design and component implementation.
  - URL: [https://m3.material.io/](https://m3.material.io/)

## 10.2 Tools and Utilities
Various specialized tools were utilized for diagramming, email communication, and infrastructure.

- **Mermaid.js**: JavaScript-based diagramming and charting tool used for DFD, ER, and Architecture diagrams.
  - URL: [https://mermaid.js.org/](https://mermaid.js.org/)
- **Resend API**: Email delivery infrastructure used for automated institutional notifications.
  - URL: [https://resend.com/docs](https://resend.com/docs)
- **PostgreSQL Reference**: Comprehensive documentation for the relational database engine.
  - URL: [https://www.postgresql.org/docs/](https://www.postgresql.org/docs/)
- **Visual Studio Code**: The primary Integrated Development Environment (IDE) used for development and documentation.
  - URL: [https://code.visualstudio.com/docs](https://code.visualstudio.com/docs)

## 10.3 Software Engineering References
- **Clean Architecture Principles**: Robert C. Martin's guidelines on software structure and modularity.
- **SOLID Principles**: Fundamental principles of object-oriented design and programming.
- **Structured Design**: Yourdon & Constantine methodology for modular system decomposition.
